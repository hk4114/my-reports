02 / FIRST RUN

六步掌握日常操作

左侧是步骤索引，右侧会随滚动切换真实操作场景。也可以直接单击任一步骤。

STEP 01

从鼠标开始

Herdr 的整个界面都可以直接点击。新用户无需先记快捷键。

CLICK聚焦单击工作区、标签页、窗格或智能体。
RIGHT CLICK打开操作菜单创建、分屏、重命名或关闭。
DRAG BORDER调整大小拖动分隔线改变窗格比例。
DRAG TEXT复制文本拖动选择终端文本即可复制。
STEP 02

把 prefix 当作顺序，而不是组合键

Ctrl+B松开 →操作键
快捷键帮助prefix+?
新建标签页prefix+c
向右分屏prefix+v
向下分屏prefix+-
窗格移动prefix+h/j/k/l
分离客户端prefix+q
以 prefix+? 显示的当前绑定为准。向下分屏时，最后按下的是 - 键。
STEP 03

在新窗格中启动 OMP

在空闲 shell 窗格中正常运行 OMP。Herdr 会自动识别进程，并在侧边栏显示生命周期状态。

new paneshell ready
omp

Herdr detects: omp

integration current (v8)

当前进程早于集成安装而启动；此后新启动的 OMP 进程将加载集成。
STEP 04

分离客户端，后台继续运行

Ctrl+B松开 →q
CLIENT已分离
HERDR SERVER仍在运行
PANES进程继续
在 Herdr 外部的普通终端重连default session
herdr
不要在当前 Herdr 窗格中运行不带参数的 herdr；嵌套启动会被阻止。
STEP 05

明确破坏性停止边界

分离只关闭客户端连接。下面的命令会停止服务器，并终止其窗格进程。

危险命令terminates pane processes
herdr server stop
布局之后可以恢复，受支持的智能体对话也可能恢复；普通命令、开发服务器与其他任意进程已经终止。
STEP 06

按证据诊断

先看运行时，再看智能体检测与集成，最后读取解释和日志。

herdr status
herdr agent list
herdr integration status
herdr agent explain <target> --json

03 / SAFETY BOUNDARY

分离与停止，后果完全不同

这是 Herdr 最重要的操作边界。先判断你是要“离开界面”，还是要“终止所有运行内容”。

Detach / safe exit

prefix+q

客户端离开。后台服务器、窗格、智能体、开发服务器与测试进程继续运行。

Herdr serverrunning
Pane processesrunning
Agent sessionlive
Server stop / destructive

herdr server stop

服务器停止，窗格中的原始进程消失。布局与部分智能体会话可恢复，但任意运行命令不会继续。

Herdr serverstopped
Pane processesterminated
Arbitrary commandsgone

05 / DIAGNOSTICS

四类证据，定位大多数问题

命令均来自 Herdr 官方指南与当前安装版本。先检查状态，再读取解释；不要猜测快捷键、检测规则或恢复行为。

Runtime

客户端与服务器

herdr agent list

herdr agent explain <target> --json
